# Auralis Lore · BETA

Historias, fanfics, personajes y familias. Parte del entorno común [Auralis](https://github.com/OscarD0823/asteoria).

Estudio de audiolibros: 12 voces sintéticas locales, narrador y personajes, marcas de diálogo, línea de tiempo, 264 efectos CC0, importación de música propia, guardado local reusable y copias .lore con audio. Exportación WAV y ZIP por capítulos. [Uso y límites de la BETA](AUDIOBOOK.md).

[Usar aplicación](https://oscard0823.github.io/auralis-lore/) · [Descargas](https://github.com/OscarD0823/auralis-lore/releases)

Código propio de esta aplicación en src/. Núcleo, dependencias y recursos compartidos en asteoria; una misma implementación genera la aplicación independiente y la global. Datos locales, sin subir documentos. Software AGPL-3.0-or-later, con avisos y licencias de terceros. Autor: OscarD0823.
